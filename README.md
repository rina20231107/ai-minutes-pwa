# ことのは議事録 PWA

iPhoneのSafariで使えるAI議事録アプリです。Phase 1では録音、一時停止・再開、音声ファイル選択、再生、共有・保存、ホーム画面への追加に対応しています。

## iPhoneでの使い方

1. 公開URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 初回録音時にマイクの使用を許可する

録音中はSafariを閉じたり画面をロックしたりしないでください。Webアプリではバックグラウンド録音が中断される場合があります。

## セキュリティ

Phase 1の音声は、ユーザーが共有・保存するまで外部へ送信されません。OpenAI APIキーはブラウザへ埋め込みません。Phase 2以降は安全なサーバー経由で文字起こしを実装します。
