# ことのは議事録 PWA

iPhoneのSafariで使えるAI議事録アプリです。Phase 4では録音、音声ファイル選択、AI文字起こし、AI議事録の作成・編集に加え、端末内の履歴保存・検索・再編集・削除に対応しています。

## iPhoneでの使い方

1. 公開URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 初回録音時にマイクの使用を許可する

録音中はSafariを閉じたり画面をロックしたりしないでください。Webアプリではバックグラウンド録音が中断される場合があります。

## セキュリティ

文字起こしまたはAI議事録作成を実行した場合のみ、処理に必要なデータが安全な中継サーバーを経由してOpenAI APIへ送信されます。OpenAI APIキーはブラウザやGitHubへ埋め込みません。
